# Визуализация: контрольный расчет и дашборд команд

Роль «Визуализация» в проекте — **независимо пересчитать на pandas все числа, которые показывают
графики**, и убедиться, что они совпадают (ТЗ: «все значения на графиках совпадают с контрольным
расчетом в pandas», T-15, T-16, T-68). Сами графики и страницы пишет разработчик дашбордов
(`dashboard/`), данные — из витрин пайплайнов. Здесь — вторая, независимая точка зрения.

## Что внутри
| Файл | Что делает |
|---|---|
| `calc.py` | контрольный расчет: итоги регионов и школ, гистограмма, доли по темам, сравнение вариантов |
| `data.py` | читает набор платформ (папка `medium`/`small` или ZIP) в pandas |
| `teams.py`, `teams_app.py`, `teams.csv` | страница «Команды»: контрольные точки и обновления репозиториев GitHub |

Тесты — в `tests/visualization/`:
- `test_viz_calc.py` — правила расчета на маленьких таблицах (удаленные, pending, дубли, null и 0, отметка 2);
- `test_viz_control.py` — **сверка с тем, что показывает дашборд**: итоги регионов, гистограммы для всех
  сочетаний фильтров, доли по темам, сравнение вариантов (источник дашборда — `DemoData` на `small.zip`);
- `test_viz_teams.py` — страница «Команды» без сети (подставной ответ GitHub, кэш при обрыве связи).

## Запуск
```bash
make test ARGS="tests/visualization -q"      # только эти тесты; базу для них запускать не нужно
make lint
streamlit run visualization/teams_app.py     # страница «Команды»
```
Токен GitHub нужен только закрытым репозиториям: `export GITHUB_TOKEN=...` (в файлы не писать).

## Как считаем (совпадает с витринами)
- в итоги идут только `finished` + `final`/`appeal_changed`; удаленные, pending, absent, annulled — нет;
- при нескольких записях участника берется с наибольшим `updated_at` (в UTC);
- `null` не равно 0; отметка 2 — из поля `grade` платформы, не пересчитывается;
- доля по темам — среднее по ответам от «балл / максимальный балл»; задания в `tasks` — пары (вариант, задание);
- отметка задания в «Сравнении вариантов»: разница между вариантами строго больше 15 п. п.
