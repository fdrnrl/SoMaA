## Команды в подготовленном окружении

Проверялись Python 3.13.7 (Windows), зависимости requirements.txt,
Streamlit 1.67.0, matplotlib 3.11.2, Playwright 1.56.0. Они установлены для проверки
во временные папки для прежнего прогона. Позднее по разрешению Дмитрия Streamlit,
matplotlib и bcrypt закреплены в requirements.txt и установлены в Linux .venv.
Цель проекта Python 3.12: Ruff target py312 и синтаксис проверены, этот итоговый
прогон не является запуском всех зависимостей под Python 3.12.

```bash
python -B -m pytest tests/dashboard -p no:cacheprovider --cov=dashboard --cov-branch
python -B -m ruff check --no-cache dashboard tests/dashboard
python -m streamlit run dashboard/app.py
```

Рабочая команда запуска требует настроенных sma_app/sma_reader и реального аккаунта.
Изолированный браузерный стенд использует только синтетику, MemoryAccounts и отдельный
процесс; это не режим обхода входа в dashboard/app.py. Запускать только локально:

```bash
python -B -m streamlit run tests/dashboard/browser_app.py --global.developmentMode false --server.address 127.0.0.1 --server.port 8507 --server.headless true --server.fileWatcherType none --browser.gatherUsageStats false
PYTHONPATH=.:tests/dashboard python -B tests/dashboard/browser_checks.py
```

В PowerShell для второй команды предварительно задать
`$env:PYTHONPATH="$PWD;$PWD\tests\dashboard"` и выполнить Python без Unix-префикса.
Тестовые логины staff/admin, пароль — TEST_PASSWORD из tests/dashboard/test_auth.py.
После изменения кода перезапустить временный сервер: наблюдение за файлами отключено.
Сценарий использует установленный Chrome, не загружает другой браузер.
Поддержка Chrome описана в [документации Playwright](https://playwright.dev/python/docs/browsers#google-chrome--microsoft-edge).
