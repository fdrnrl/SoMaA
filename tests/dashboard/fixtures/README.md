# Small для автономной разработки дашборда

Данные синтетические; выводы ограничены свойствами генератора.

- `small.zip` — готовый small из предоставленного архива v2, включая manifest, ключ и timeline. Исходные файлы сохранены без изменений; проверены 77 SHA-256 из manifest.
- `small_summary.json` — происхождение, контрольные суммы, модельное время, счетчики четырех платформ и контрольные итоги по 12 сочетаниям экзамен/предмет/регион.
- Снимок: after_appeal, 2026-12-11T12:00:00+03:00. Идущих сессий нет. Это статические данные.
- Контроль итогов использует только finished с final/appeal_changed, исключает deleted и берет последнюю версию по естественному ключу, как текущая sessions_current.

Генератор проекта не запускался. SQL-витрины, права БД и автоматическое обновление этими файлами не проверены. Ключ набора не заменяет сохраненные результаты аналитика.

## Загрузка коллегой после подготовки отдельной БД

Предлагаемое имя БД: `sma_dashboard_dev`. Сначала тимлид/пайплайнер подготавливает ее, применяет миграции и настройки доступа. Команды ниже выполняются из корня проекта в подготовленной Ubuntu; файлы проекта менять не требуется.

```bash
small_dir="$(mktemp -d)"
python3.12 -m zipfile -e tests/dashboard/fixtures/small.zip "$small_dir"
POSTGRES_DB=sma_dashboard_dev make load-files DATA="$small_dir"
```

Команда загрузки изменяет только указанную отдельную БД. Рабочую БД команды и `sma_test` для pytest не использовать; сброс базы не нужен. До подготовки настроек команду не запускать.
